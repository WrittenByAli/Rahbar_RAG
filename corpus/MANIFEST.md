## Deliberately Absent Topics

- **Student housing / dormitory policy** — intentionally excluded; used for must-abstain evaluation questions.
- **Sports and athletics policy** — not in corpus; used for additional abstain coverage.

## Notes

- Documents are fetched via `python corpus/fetch.py` from URLs in `corpus/sources.yaml`.
- Raw files live in `corpus/raw/` (gitignored, never committed).
- The `_index.json` file generated by `fetch.py` drives the indexer's `discover()` function.
- Document 7 (Faculty Entrepreneurship Policy) is a scanned image PDF; `pdfplumber` extracts no text, so it falls through to the OCR path (`pytesseract` + `pdf2image`).
- SHA-256 checksums are computed at fetch time and recorded for integrity verification.
